Relax Park is a premium booking landing page designed for luxury country resorts, nature retreats, and high-end hospitality complexes. It provides a seamless, immersive digital experience for showcasing villas, suites, and glamping accommodations.

## 🎯 Target Audience & Purpose

This project is tailored for **premium hospitality businesses** that want to convey exclusivity and tranquility through their digital presence. 
Whether it's a boutique hotel, an eco-resort, or a luxury glamping site, Relax Park offers a sophisticated platform to:
- Showcase exquisite accommodations with high-quality visual galleries.
- Provide a seamless and intuitive booking flow.
- Immerse the user in the "Quiet Luxury" aesthetic even before their arrival.

## ✨ Key Features

- **Premium Animations**: Smooth, cinematic transitions and fluid scrolling powered by GSAP and Lenis, creating a highly polished user experience.
- **Design System**: A bespoke `tokens.css` token system utilizing a carefully curated color palette (charcoal, gold, sage, sand) to reflect the "Quiet Luxury" aesthetic.
- **Bilingual Support**: Built-in translation system supporting both English and Russian to cater to an international audience.
- **Lightning Fast Performance**: Leverages Next.js Static Site Generation (SSG) and fully local asset hosting for instantaneous load times and zero dependency on external media APIs.
- **Flawless Responsiveness**: A meticulously crafted UI that looks and performs perfectly across all devices, from ultra-wide desktop monitors to mobile phones.

## 🎨 Design Philosophy (Quiet Luxury)

The visual identity of Relax Park is rooted in the concept of **Quiet Luxury**. It avoids flashy elements in favor of refined minimalism, natural tones, and sophisticated typography.

**Core Color Palette:**
- **Charcoal** (`#1C1D1A`): A deep, grounding dark tone used for backgrounds and text.
- **Gold** (`#C5A880`): An elegant accent color for calls to action and highlights.
- **Sage** (`#8A9A86`): A calming, nature-inspired secondary tone.
- **Sand** (`#E8E5DF`): A soft, welcoming light background.

## 🏗 Tech Stack

Built with a focus on modern web standards, performance, and developer experience:
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS combined with native CSS variables
- **Motion**: GSAP (GreenSock Animation Platform) & Lenis Scroll
